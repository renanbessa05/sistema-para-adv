# Runbook: suporte

Quem: equipe de suporte do sistema (papel `suporte`), com acesso ao escritório concedido pelo próprio escritório por prazo determinado.

## O que o suporte pode

- Ver o painel do escritório em modo leitura, enquanto o acesso estiver vigente (`acessos_suporte`).
- Ver `/admin/status` do escritório: rotinas, alertas e backups.
- Abrir incidente seguindo `docs/runbooks/incidente.md`.

## O que o suporte não pode

- Escrever dados do escritório pela interface. Qualquer correção de dado passa pelo sócio.
- Ver ou copiar backups. A restauração é manual e exige sócio (`docs/runbooks/restauracao-por-tenant.md`).
- Pedir senha, código de segundo fator ou chave de API a usuário.

## Atendimento

- Canal de atendimento e horário: (a confirmar).
- Dados pessoais no chamado: só o necessário. Não colar processo, cliente ou mensagem.
- Encerrar o acesso de suporte ao fim do atendimento, se o escritório pedir.
