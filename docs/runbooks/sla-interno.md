# SLA interno (operação)

Este documento define metas **internas** de resposta. Não é contrato com cliente. Todos os valores estão a confirmar pelo sócio responsável.

| Severidade | Exemplo | Primeira resposta | Início do tratamento | Status |
|---|---|---|---|---|
| critica | sistema fora do ar para todo o escritório; vazamento suspeito | (a confirmar) | (a confirmar) | `/status` e incidente aberto |
| alta | rotina de captação parada; backup falhando | (a confirmar) | (a confirmar) | incidente aberto |
| media | erro isolado em uma tela | (a confirmar) | (a confirmar) | chamado |
| baixa | dúvida de uso, ajuste de cadastro | (a confirmar) | (a confirmar) | chamado |

- Prazos processuais não dependem deste SLA: o escritório mantém o plano B (exportação diária de prazos por e-mail aos sócios) e o acompanhamento no sistema do tribunal.
- Revisar esta tabela a cada trimestre (a confirmar quem revisa).
